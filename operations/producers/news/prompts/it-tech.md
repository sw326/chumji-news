# IT/테크 브리핑 템플릿

## 형식 (이 형식을 정확히 따를 것)

```
💻 YYYY.MM.DD (요일) IT/테크 브리핑

🌐 해외

🤖 **헤드라인**
설명 1-2줄 + 왜 중요한지 한마디
[출처명](https://실제기사URL)

(4-5개, 이모지 활용 — AI/반도체/클라우드/스타트업/빅테크 등)

🇰🇷 국내

📱 **헤드라인**
설명 1-2줄 + 왜 중요한지 한마디
[출처명](https://실제기사URL)

(3-4개)

🔥 테크 핫토픽
• 토픽1: 한줄 요약
• 토픽2: 한줄 요약
• 토픽3: 한줄 요약
```

## 규칙 (⚠️ 절대 어기지 말 것!)
1. **출처는 반드시 클릭 가능한 마크다운 링크**: `[TechCrunch](https://techcrunch.com/2026/03/04/article-title)` ✅ / `[TechCrunch](https://techcrunch.com)` ❌
2. **URL은 RSS `<link>` 요소의 실제 기사 URL 그대로 사용**. 언론사 홈페이지·섹션 페이지 URL 절대 금지. URL 없으면 해당 기사 제외.
3. **리포트 본문만 전송** — 인사말, 진행 메시지, "전송 완료" 일체 금지
4. **이 템플릿 형식 고정** — 섹션 순서, 이모지, 구조를 매번 동일하게
5. **각 뉴스에 '왜 중요한지' 한마디 포함** (개발자/IT인 관점)
6. **모든 헤드라인·설명은 한국어로 번역** — 영어 원문 그대로 쓰지 말 것

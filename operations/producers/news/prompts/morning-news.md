# 아침 뉴스 브리핑 템플릿

## 형식 (이 형식을 정확히 따를 것)

```
📰 YYYY.MM.DD (요일) 아침 뉴스 브리핑

🌍 해외

🇽🇽 **헤드라인**
설명 1-2줄
[언론사명](https://실제기사URL)

(3-4개, 국기 이모지 활용)

📰 보수 언론

💼 **헤드라인**
설명 1-2줄
[조선일보](https://실제기사URL)

(2-3개)

📰 진보 언론

📢 **헤드라인**
설명 1-2줄
[경향신문](https://실제기사URL)

(2-3개)

📈 증시 (전일 종가)
• 코스피: X,XXX (±X.XX%)
• 코스닥: X,XXX (±X.XX%)
• 원/달러: X,XXX원

🔥 핫이슈 TOP 3
• 이슈 1
• 이슈 2
• 이슈 3
```

## 규칙 (⚠️ 절대 어기지 말 것!)
1. **출처는 반드시 클릭 가능한 마크다운 링크**: `[BBC](https://www.bbc.com/news/articles/cxxx)` ✅ / `[BBC](https://www.bbc.com)` ❌
2. **URL은 RSS `<link>` 요소의 실제 기사 URL 그대로 사용**. 언론사 홈페이지·섹션 URL 절대 금지. URL 없으면 해당 기사 제외.
3. **리포트 본문만 전송** — 인사말, 진행 메시지, "전송 완료" 일체 금지
4. **이 템플릿 형식 고정** — 섹션 순서, 이모지, 구조를 매번 동일하게
5. **모든 헤드라인·설명은 한국어로 번역** — 영어 원문 그대로 쓰지 말 것. 제목도 번역, 설명도 번역.

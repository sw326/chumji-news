# 연구 프로토콜

```text
관측 → 질문 경계 → 경쟁 가설 → 최소 필요 증거
→ 출처 탐색 → 일회성 검증 → 반복 수집 승격
→ 분석 가능성 재판정 → 결론과 한계
```

## 규칙

- 질문이 필요한 증거를 결정한다.
- 증거가 부족하면 수단을 늘리거나 질문을 줄인다.
- 질문을 유지한 채 자료 없이 해석만 넓히지 않는다.
- `관측 사실`, `외부 주장`, `잠정 해석`, `탐색 가설`, `확인 불가`를 구분한다.
- 원인 주장은 작동 경로와 중간 지표가 관측될 때만 강화한다.
- 같은 이름, 다른 기간·단위·통화·분류 범위를 자동으로 합치지 않는다.

## 출처 승격 단계

`discovered → accessible → understood → validated → repeatable → operational → analysis-ready`

처음 발견한 외부 자료는 `sources` 또는 `raw`에만 들어간다. 검증을 통과하기 전에는 엔티티·개념 페이지의 확정 사실이 아니다.
